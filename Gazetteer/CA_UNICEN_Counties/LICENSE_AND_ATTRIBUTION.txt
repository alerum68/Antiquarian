Canadian Census Division (CD) historical boundaries, 1851-1921
================================================================

Eight shapefiles (cd_1851 .. cd_1921), one per Canadian census year, at the
Census Division (CD - roughly equivalent to a US county) level. Projection:
WGS84 / EPSG:4326. "CBF-Harmonized Shorelines" series (coastlines kept
consistent across years for cleaner time-series joins).

Source / distribution
----------------------
Downloaded from the UNI-CEN Project (Unified Infrastructure for Canadian
Census Research), Western University, via Borealis Dataverse:
  https://borealisdata.ca/dataverse/unicen_boundaries
  https://observatory.uwo.ca/unicen

Each file's own `source` column reads "TCP", confirming the underlying
geometry originates from The Canadian Peoples / Les populations canadiennes
project (the same project behind the CCRI-branded CD_1911 file also present
in this repo's history) - UNI-CEN's contribution is harmonizing shorelines
and re-projecting to WGS84 across all 8 years in one consistent schema.

Columns
-------
geosid    - unique ID; first 2 letters are the province/territory code
            (AB, BC, MB, NB, NS, ON, PE, QC, SK, ...) - no separate
            province column
time      - census year (string)
level     - numeric level code (3 = CD for this series)
geoname   - the CD's own name (e.g. "Calgary", "Yale & Cariboo")
lat_c/lon_c, lat_r/lon_r - centroid coordinates
areakm    - polygon area in square km
source    - "TCP" for every row in every year
