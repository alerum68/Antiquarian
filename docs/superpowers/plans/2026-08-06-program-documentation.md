# Scriptorium Documentation

Scriptorium is a desktop toolkit for genealogy research that extracts structured data from large historical record collections and turns them into GEDCOM family tree files.

It manages repetitive archival tasks:
1. Downloading high-resolution document images and existing indexes (**Voyageur**).

4. Scanning tree databases for duplicates and standardizing historical county boundaries (**Registrar** and **Gazetteer**).

# Getting Started with Scriptorium

## System Requirements

- **Operating System**: Windows 10 or Windows 11 (64-bit).
- **Python**: Python 3.12 or newer.
- **Browser**: Google Chrome, Microsoft Edge, or Mozilla Firefox with the TamperMonkey extension (required for Ancestry and FamilySearch gathers).
- **AI Access**: A Google Gemini API key.

---

## Installation Steps

1. **Clone or Download the Repository**:
   ```bash
   git clone https://github.com/alerum68/Scriptorium.git
   cd Scriptorium
   ```

2. **Set Up a Virtual Environment**:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   ```

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Install the TamperMonkey Browser Script**:
   - Open TamperMonkey in your browser.
   - Create a new userscript and paste the contents of `Voyageur/Voyageur.js`.
   - Save and enable the script. It automatically detects Ancestry and FamilySearch record pages.

5. **Launch the Application**:
   ```bash
   python Scriptorium.py
   ```

---

## First-Run Setup

When Scriptorium opens, navigate to the **Global Settings** tab:
1. Enter your Google Gemini API key.
2. Configure your working directories:
   - **Root Project Directory**: Where your project data and master databases live.
   - **Raw Downloads Directory**: Where Voyageur places downloaded images.
   - **Output Directory**: Where Archivist exports GEDCOM files.
3. Click **Save Settings**.
```

# Voyageur (Gather) User Guide

Voyageur handles automated retrieval of archival images and index data from online repositories.

---

## Supported Repositories

### 1. Library and Archives Canada (LAC) & Canadiana
- **Microfilm Reels & Volume Assets**: Direct programmatic downloading without requiring browser automation.
- **Usage**:
  1. Select the **LAC** tab in Voyageur.
  2. Enter the Heritage Canadiana reel number (e.g., `C-12345`) or LAC volume ID.
  3. Specify page ranges if downloading a portion of a volume.
  4. Click **Start Download**. Images download with multi-threaded workers and automatically populate a scaffold Master DB JSON.

### 2. FamilySearch Church Registers
- **Image Index & Citation Retrieval**:
  1. Open the target church register film page on FamilySearch in your browser.
  2. The `Voyageur.js` TamperMonkey script will display a floating gather control.
  3. Click **Extract Index Data**. Voyageur captures the Image Index table, transcriptions, and citation metadata.
  4. Duplicate entries referencing overlapping film segments are linked automatically.

### 3. Ancestry Census Records
- **Scraped Transcriptions & Image Retrieval**:
  1. Navigate to the desired census page on Ancestry with TamperMonkey active.
  2. Click **Capture Record**. The script extracts all household rows and initiates image download into your configured downloads staging folder.

---

## Tips for Stable Downloads

- **Rate Limits**: If downloading large microfilm rolls (1,000+ pages), keep download concurrency at 2-3 workers to avoid temporary HTTP 429 throttling from archival servers.
- **Interrupted Downloads**: Voyageur maintains a `.checkpoint` JSON file in the target folder. If interrupted, restarting the gather resumes from the last completed page without refetching existing images.
```

# Paleographer (Analyze) User Guide

Paleographer reads historical document images and transcribes handwritten records into structured JSON using configured AI models.

---

## Processing Modes

### 1. Single Sheet / Interactive Mode
Use this when reviewing challenging handwriting or testing prompt accuracy:
1. Select the record type from the dropdown:
   - **Parish**: Baptism, marriage, and burial registers with priest, witness, and godparent roles.
   - **Scrip**: Métis scrip applications, affidavits, powers of attorney, and discharge certificates.
   - **Census**: Population schedules, household groupings, and demographic facts.
2. Select an image file or PDF page.
3. Click **Transcribe Sheet**.
4. The transcription results appear in the review editor. Make any manual corrections in the data table.
5. Click **Save to Master DB**.

### 2. Batch Processing Mode
Use this for full books, microfilm folders, or large document batches:
1. Point Paleographer to a directory containing page images (`.jpg`, `.png`, `.tif`, `.pdf`).
2. Click **Start Batch Analysis**.
3. Paleographer runs each page through the extraction engine in the background and continuously appends verified sheets to `MasterDB_<collection>.json`.

---

## Reviewing Master DB Records

The Master DB editor allows quick verification of extracted fields:
- **Names**: Standardized given names and surnames alongside verbatim extracted spellings.
- **Dates & Places**: Standardized Gregorian dates and historical place descriptions.
- **Roles**: Correct assignment of roles (e.g., Groom, Bride, Father, Mother, Godmother, Witness).
- **Facts**: Specific attributes like age, marital status, occupation, or condition flags.

---

## Customizing Prompts

Record extraction formats are defined in `.pmt` files located in the `Paleographer/prompts/` directory:
- `Parish.pmt`
- `Scrip.pmt`
- `Census.pmt`

Each file contains front-matter schema constraints and prompt instructions. You can edit prompt guidelines to add domain-specific vocabulary or historical terminology relevant to your collection.
```

# Archivist (Create) User Guide

Archivist transforms structured Master DB JSON files into standardized GEDCOM 5.5.1 genealogy trees ready for import into RootsMagic, Family Tree Maker, or Ancestry.

---

## How It Works

1. Open the **Archivist** tab.
2. Select your `MasterDB_<collection>.json` file (or let Archivist auto-select the most recently created database).
3. Select your export options:
   - **Include Source Citations**: Attaches page-level citations and archival repository metadata to every created event.
   - **Link Godparents and Witnesses**: Creates GEDCOM 5.5.1 `_ASSO` association tags or secondary event notes for non-family participants.
   - **Flag Ambiguities**: Inserts research notes (`NOTE`) for entries where handwriting confidence was low.
4. Click **Generate GEDCOM**.
5. The resulting `.ged` file is saved to your configured output folder.

---

## Importing into Genealogy Software

### RootsMagic
1. In RootsMagic, open or create a target database.
2. Select **File → Import → GEDCOM**.
3. Choose the `.ged` file generated by Archivist.
4. Review the import summary. Source citations and repository records link directly to the imported events.

### Family Tree Maker
1. Select **File → Open**.
2. Change the file type filter to **GEDCOM Files (*.ged)**.
3. Follow the import wizard prompts to merge into an existing tree or create a new project.
```

# Registrar & Gazetteer Maintenance Tools

The Registrar and Gazetteer tools perform automated database cleanup and geographical standardization directly on RootsMagic database files (`.rmtree`).

---

## Safety Precaution: Database Backup

> **CRITICAL**: Both tools modify database records directly.
> 1. **Close RootsMagic completely** before running Registrar or Gazetteer.
> 2. **Make a backup copy** of your `.rmtree` file before proceeding.

---

## Registrar: Duplicate Person Detection

Registrar scans your database for individuals who may have been entered multiple times under slight name variations, alternate spellings, or estimated birth dates.

### Using Registrar:
1. Select the **Registrar** tab in Scriptorium.
2. Point to your `.rmtree` file.
3. Configure matching thresholds:
   - **Name Match Sensitivity**: Strict, Moderate, or Fuzzy (Metaphone / Levenshtein).
   - **Birth Year Tolerance**: Acceptable date variance (e.g., ±2 years).
   - **Parent Matching**: Check whether parents' names must match to trigger a duplicate flag.
4. Click **Scan for Duplicates**.
5. Registrar creates RootsMagic **To-Do / Task** entries for each candidate duplicate pair, allowing you to review and merge them inside RootsMagic.

---

## Gazetteer: Historical County Boundary Normalization

Modern county names often do not match the historical jurisdictions that existed when an event took place. Gazetteer adjusts place names in your tree to reflect historical boundaries at the exact date of the event.

### Using Gazetteer:
1. Ensure the Newberry Atlas of Historical County Boundaries shapefile dataset is downloaded and extracted in your configured Newberry directory.
2. Select your `.rmtree` file in the **Gazetteer** tab.
3. Click **Analyze Places**.
4. Gazetteer compares each event date and coordinate/place against the historical boundary database.
5. Click **Apply Standardized Names** to update place records.
```

# PDFix Utility Guide

PDFix is a document preparation utility designed to repair broken PDF files and extract high-resolution page images for processing in Paleographer.

---

## Features

- **High-Resolution Page Extraction**: Converts PDF pages into uncompressed `.jpg` or `.png` images suitable for OCR and vision-based AI transcription.
- **Corrupted PDF Recovery**: Fixes broken xref tables, linearized streams, and missing EOF markers commonly found in legacy archival scans.
- **Batch Splitting**: Splits multi-hundred-page PDF volumes into single-page assets organized by page number.

---

## Usage

1. Open the **PDFix** tab in Scriptorium.
2. Select an input PDF file or a folder of PDFs.
3. Choose the target output directory and image format (`JPG` at 300 DPI recommended).
4. Click **Extract Images**.

# Troubleshooting & FAQ

## Common Issues & Solutions

### 1. TamperMonkey script is not capturing records
- **Cause**: Browser permissions or script matching rules are outdated.
- **Fix**: Check that `Voyageur.js` is enabled in TamperMonkey. Ensure you are on the supported record view URL on Ancestry or FamilySearch.

### 2. Paleographer reports "API Rate Limit Exceeded" (HTTP 429)
- **Cause**: Exceeded provider request quota or tokens-per-minute limits.
- **Fix**: Paleographer automatically retries with exponential backoff. For large batch runs, reduce batch concurrency or verify tier quota in your provider account dashboard.

### 3. Database locked error in Registrar / Gazetteer
- **Cause**: RootsMagic is currently running and holding an exclusive SQLite file lock.
- **Fix**: Close RootsMagic completely. Check Task Manager to ensure no background `RootsMagic.exe` process remains active.

### 4. Image download incomplete or corrupt
- **Cause**: Network interruption during LAC/Canadiana microfilm download.
- **Fix**: Re-run the gather command for the same reel or volume. Voyageur checks existing files on disk and resumes downloading only missing or zero-byte images.
```
